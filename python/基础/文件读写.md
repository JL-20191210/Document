## 1. **打开文件** - `open()`

Python 使用 `open()` 函数来打开文件并返回文件对象。常用模式如下：
- `'r'`：读取模式（默认）。文件必须存在。
- `'w'`：写入模式。如果文件不存在，会创建文件；如果文件存在，先清空文件内容。
- `'a'`：追加模式。如果文件存在，文件指针会在文件末尾追加内容。
- `'b'`：二进制模式，处理非文本文件，如图片、音频等。可以与其他模式结合使用，如 `'rb'`、`'wb'`。
- `'x'`：写入模式（排他模式）。如果文件已存在，抛出异常。
- `'+'`：读写模式。可以与 `'r'`、`'w'`、`'a'` 结合使用，如 `'r+'`、`'w+'`。

```python
f = open('file.txt', 'r')  # 读取模式打开文件
```

## 2. **读取文件的方法**

- **`f.read(size)`**：
    
    - 读取整个文件或指定的字节数。
  - 如果 `size` 参数被忽略或为负数，读取整个文件。
  ```python
  with open('file.txt', 'r') as f:
      content = f.read()  # 读取文件所有内容
    ```
    
- **`f.readline()`**：
    - 逐行读取文件，每次调用返回一行，包含行末的换行符。
    - 使用循环可以逐行读取文件。
  ```python
  with open('file.txt', 'r') as f:
      line = f.readline()  # 读取第一行
  ```

- **`f.readlines()`**：
    - 一次读取整个文件，并将每一行作为一个字符串存储在列表中。
    - 使用时占用较多内存，适合文件较小时使用。
  ```python
  with open('file.txt', 'r') as f:
      lines = f.readlines()  # 读取所有行，返回一个列表
  ```

- **`for line in f`**：
    - 通过遍历文件对象逐行读取，效率高于 `readlines()`。
  ```python
  with open('file.txt', 'r') as f:
      for line in f:
          print(line, end='')  # 按行读取文件
  ```

## 3. **写入文件的方法**

- **`f.write(string)`**：
    
  - 将字符串写入文件。返回写入的字符数。
  ```python
  with open('file.txt', 'w') as f:
      f.write("Hello, World!")
    ```
    
- **`f.writelines(list_of_strings)`**：
    - 将字符串列表写入文件，每个字符串作为一行。注意 `writelines()` 不会自动添加换行符，需手动在字符串末尾加 `\n`。
  ```python
  lines = ["First line\n", "Second line\n"]
  with open('file.txt', 'w') as f:
      f.writelines(lines)
  ```

## 4. **追加文件的方法**

- **`f.write(string)` with `'a'` mode**：
    - 在文件末尾追加内容，而不覆盖现有内容。
  ```python
  with open('file.txt', 'a') as f:
      f.write("This is appended text.\n")
  ```

## 5. **处理二进制文件**

- **`f.read(size)` in binary mode**：
    - 用于读取二进制文件，如图片、音频文件等。与文本模式类似，但返回 `bytes` 对象。
  ```python
  with open('image.png', 'rb') as f:
      data = f.read()  # 读取二进制文件
  ```

- **`f.write(bytes)` in binary mode**：
    - 用于写入二进制数据。`write()` 的参数需要是 `bytes` 对象。
  ```python
  with open('output.png', 'wb') as f:
      f.write(data)  # 将二进制数据写入文件
  ```

## 6. **文件指针操作**

- **`f.seek(offset, from_what)`**：
    - 移动文件指针到指定位置。
    - `offset` 是字节数，`from_what` 的值为：`0` (文件开头)、`1` (当前位置)、`2` (文件末尾)。
  ```python
  with open('file.txt', 'r') as f:
      f.seek(5)  # 文件指针移动到第 5 个字节
  ```

- **`f.tell()`**：
    - 返回文件指针的当前位置（字节位置）。
  ```python
  with open('file.txt', 'r') as f:
      position = f.tell()  # 获取文件指针的当前位置
  ```

## 7. **关闭文件**

- **`f.close()`**：
    - 显式关闭文件。虽然使用 `with` 语句时会自动关闭文件，但在不使用 `with` 的情况下，手动关闭文件是个好习惯。
  ```python
  f = open('file.txt', 'r')
  f.read()
  f.close()  # 手动关闭文件
  ```

## 8. **文件上下文管理器**

- **`with open()`**：
    - `with` 语句可以确保文件操作结束后自动关闭文件，不需要显式调用 `close()`。
  ```python
  with open('file.txt', 'r') as f:
      content = f.read()  # 文件将在退出 with 块时自动关闭
  ```

## 9. **异常处理**

- 文件操作时可能会出现异常（如文件不存在、权限不足等）。可以使用 `try...except` 语句来捕获这些异常：
  ```python
  try:
      with open('file.txt', 'r') as f:
          content = f.read()
  except FileNotFoundError:
      print("File not found!")
  ```

### 总结

- **读取文件**：`f.read()`、`f.readline()`、`f.readlines()`、`for line in f`
- **写入文件**：`f.write()`、`f.writelines()`
- **追加文件**：`f.write()` in `'a'` mode
- **二进制操作**：使用 `'rb'`、`'wb'` 模式
- **文件指针操作**：`f.seek()`、`f.tell()`
- **自动关闭文件**：使用 `with open()`
